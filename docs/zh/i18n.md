# i18n — Language

翻译文件、`__()` 辅助函数，以及编译后的语言映射的自动缓存。

```php
use alirezax5\TelegramBase\App\Language\Language;
```

## 文件布局

一切位于 `LANG_DIR` 之下（默认 `/Language`，相对于项目根目录解析——`Bootstrap` 会替你接好 `Paths::base() . LANG_DIR`）。

```
Language/
├── fa.php            # main file for 'fa' — keys as-is
└── fa/               # optional subdirectory — keys get a '<filename>.' prefix
    ├── main.php      #   → main.ali, main.other, …
    └── buttons.php   #   → buttons.save, buttons.cancel, …
```

- **主文件**是 `{LANG_DIR}/{lang}.php`；**子目录**是 `{LANG_DIR}/{lang}/`，其中的每个文件按字母序加载，并以文件 basename 作为键前缀。
- 嵌套数组被扁平化为**点记法**：`['btn' => ['btna' => 'hi']]` → `btn.btna`。
- 文件格式由 `LANG_DRIVER` 决定：

> ⚠️ **`LANG_DRIVER` 必须与你的文件格式匹配。** 默认值是 `json`，但仓库附带的是 PHP 数组文件（`fa.php`、`fa/main.php`），且 `.env.example` 设置了 `LANG_DRIVER="php"`。在不匹配的情况下（json 驱动 + .php 文件），每次查找都会静默回退到键名——没有报错，只有未翻译的文本。这一确切场景在 P-CACHE 实测中复现过：在设置 `LANG_DRIVER=php` 之前，`__('key')` 一直返回 `"key"`。

```dotenv
LANG_DRIVER=php        # json | php — format of the language files
DEFAULT_LANG=fa        # boot language (Persian, RTL)
LANG_DIR=/Language
LANG_CACHE_TTL=60      # seconds the compiled map stays in cache
```

## `__()` 辅助函数

```php
// translations: 'welcome' => 'سلام #name خوش آمدی'
__('welcome', ['name' => 'علی']);          // "سلام علی خوش آمدی"
__('missing_key', 'پیش‌فرض');              // fallback when the key is absent
__('missing_key');                          // falls back to the key name itself
```

替换使用 `#placeholder` 语法；映射的键写作不带 `#` 的形式：

```php
__('greeting', 'default', ['name' => $firstName, 'count' => 3]);
```

Language 单例：

```php
$lang = Language::getInstance();

$lang->setLanguage('en');        // switch language (per process — call it per update if users differ)
$lang->get('key', $default, $replacements);
$lang->has('key');               // exists in the current language?
$lang->getAll();                 // full flat map
$lang->getCurrentLanguage();

$lang->reloadLanguage('fa');     // drop cache + re-read files
$lang->clearCache();             // forget lang:* cache keys
$lang->getCacheStats();          // per-language entry counts + freshness
```

## 插件中的按用户语言

`Language` 是一个按进程的单例——当前语言作用于该进程中 `setLanguage()` 之后运行的一切。对于按用户选择语言（Webhook/队列部署），在处理器开头解析并设置它：

```php
$userLang = $session->get('lang', 'fa');          // or read from your users table
Language::getInstance()->setLanguage($userLang);
$tg->sendMessage($chatId, __('menu_title'));
```

在单进程轮询守护进程中，更新中途的切换会泄漏到后续更新，除非你切换回来——更好的做法是每次更新都无条件地设置它。

## 缓存行为（已验证）

一个语言的首次加载会读取文件、扁平化映射，并将其存储在缓存键 `lang:{lang}` 下，TTL 为 `LANG_CACHE_TTL`。后续加载（包括全新进程）会命中缓存——P-CACHE 运行显示完整载荷（`{"key":"value","btn.btna":"hi","main.ali":"asfaf132"}`）在 `file`、`redis` 和 `memcached` 上跨进程存续，后端 TTL 恰好从 60 秒开始倒数。缺失的翻译键会被记录在 `lang:missing_keys` 中，并在每次更新迭代时清空一次（`Core::cleanup()` → `flushMissingKeys()`），这让调试未翻译的字符串变得轻而易举——去缓存/日志中查看键列表即可。

## 脚手架

```bash
php bin/tgbase make:language en     # creates Language/en.php scaffold
```

如果你更喜欢 JSON 文件，`Language/fa.json.example` 展示了 JSON 格式（然后将 `LANG_DRIVER` 设为 `json`）。
