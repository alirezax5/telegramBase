# i18n — Language

Fichiers de traduction, helper `__()` et mise en cache automatique des maps de langue compilées.

```php
use alirezax5\TelegramBase\App\Language\Language;
```

## Disposition des fichiers

Tout se trouve sous `LANG_DIR` (défaut `/Language`, résolu par rapport à la base du projet — `Bootstrap` câble `Paths::base() . LANG_DIR` pour vous).

```
Language/
├── fa.php            # main file for 'fa' — keys as-is
└── fa/               # optional subdirectory — keys get a '<filename>.' prefix
    ├── main.php      #   → main.ali, main.other, …
    └── buttons.php   #   → buttons.save, buttons.cancel, …
```

- Le **fichier principal** est `{LANG_DIR}/{lang}.php` ; le **sous-répertoire** est `{LANG_DIR}/{lang}/` et chaque fichier qu'il contient est chargé par ordre alphabétique avec le nom de base du fichier comme préfixe de clé.
- Les tableaux imbriqués sont aplatis en **notation par points** : `['btn' => ['btna' => 'hi']]` → `btn.btna`.
- Le format des fichiers suit `LANG_DRIVER` :

> ⚠️ **`LANG_DRIVER` doit correspondre au format de vos fichiers.** Le défaut est `json`, mais le dépôt livre des fichiers tableaux PHP (`fa.php`, `fa/main.php`) et `.env.example` définit `LANG_DRIVER="php"`. Avec la discordance (driver json + fichiers .php), chaque recherche retombe silencieusement sur le nom de la clé — pas d'erreur, juste du texte non traduit. Ce scénario exact a été reproduit pendant les tests en conditions réelles P-CACHE : `__('key')` renvoyait `"key"` jusqu'à ce que `LANG_DRIVER=php` soit défini.

```dotenv
LANG_DRIVER=php        # json | php — format of the language files
DEFAULT_LANG=fa        # boot language (Persian, RTL)
LANG_DIR=/Language
LANG_CACHE_TTL=60      # seconds the compiled map stays in cache
```

## Le helper `__()`

```php
// translations: 'welcome' => 'سلام #name خوش آمدی'
__('welcome', ['name' => 'علی']);          // "سلام علی خوش آمدی"
__('missing_key', 'پیش‌فرض');              // fallback when the key is absent
__('missing_key');                          // falls back to the key name itself
```

Les remplacements utilisent la syntaxe `#placeholder` ; les clés de la map s'écrivent sans le `#` :

```php
__('greeting', 'default', ['name' => $firstName, 'count' => 3]);
```

Singleton Language :

```php
$lang = Language::getInstance();

$lang->setLanguage('en');        // switch language (per process — call it per update if users differ)
$lang->get('key', $default, $replacements);
$lang->has('key');               // exists in the current language?
$lang->getAll();                 // full flat map
$lang->getCurrentLanguage();

$lang->reloadLanguage('fa');     // drop cache + re-read files
$lang->clearCache();             // forget lang:* cache keys
$lang->getCacheStats();          // per-language entry counts + freshness
```

## Langue par utilisateur dans un plugin

`Language` est un singleton par processus — la langue courante s'applique à tout ce qui s'exécute après `setLanguage()` dans ce processus. Pour une sélection de langue par utilisateur (déploiements webhook/file), résolvez-la et définissez-la en haut du handler :

```php
$userLang = $session->get('lang', 'fa');          // or read from your users table
Language::getInstance()->setLanguage($userLang);
$tg->sendMessage($chatId, __('menu_title'));
```

Dans un démon de polling mono-processus, un changement en milieu d'update fuit vers les updates suivants si vous ne revenez pas en arrière — préférez le définir par update, inconditionnellement.

## Comportement du cache (vérifié)

Le premier chargement d'une langue lit les fichiers, aplatit la map et la stocke sous la clé de cache `lang:{lang}` avec `LANG_CACHE_TTL`. Les chargements suivants (y compris depuis des processus frais) touchent le cache — l'exécution P-CACHE a montré la charge utile complète (`{"key":"value","btn.btna":"hi","main.ali":"asfaf132"}`) survivant entre processus sur `file`, `redis` et `memcached`, avec le TTL du backend décompté depuis exactement 60 s. Les clés de traduction manquantes sont suivies dans `lang:missing_keys` et purgées une fois par itération d'update (`Core::cleanup()` → `flushMissingKeys()`), ce qui rend le débogage des chaînes non traduites trivial — consultez le cache/les journaux pour la liste des clés.

## Scaffolding

```bash
php bin/tgbase make:language en     # creates Language/en.php scaffold
```

`Language/fa.json.example` montre le format JSON si vous préférez des fichiers JSON (dans ce cas définissez `LANG_DRIVER=json`).
