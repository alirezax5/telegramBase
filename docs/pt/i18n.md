# i18n — Language

Arquivos de tradução, o helper `__()` e o cache automático dos mapas de idioma compilados.

```php
use alirezax5\TelegramBase\App\Language\Language;
```

## Layout dos arquivos

Tudo vive sob `LANG_DIR` (padrão `/Language`, resolvido contra a base do projeto — o `Bootstrap` conecta `Paths::base() . LANG_DIR` para você).

```
Language/
├── fa.php            # main file for 'fa' — keys as-is
└── fa/               # optional subdirectory — keys get a '<filename>.' prefix
    ├── main.php      #   → main.ali, main.other, …
    └── buttons.php   #   → buttons.save, buttons.cancel, …
```

- O **arquivo principal** é `{LANG_DIR}/{lang}.php`; o **subdiretório** é `{LANG_DIR}/{lang}/` e cada arquivo nele é carregado em ordem alfabética com o basename do arquivo como prefixo de chave.
- Arrays aninhados são achatados em **notação de ponto**: `['btn' => ['btna' => 'hi']]` → `btn.btna`.
- O formato dos arquivos segue `LANG_DRIVER`:

> ⚠️ **O `LANG_DRIVER` deve corresponder ao formato dos seus arquivos.** O padrão é `json`, mas o repositório inclui arquivos em array PHP (`fa.php`, `fa/main.php`) e o `.env.example` define `LANG_DRIVER="php"`. Com a divergência (driver json + arquivos .php) toda busca silenciosamente volta ao nome da chave — nenhum erro, apenas texto não traduzido. Esse cenário exato foi reproduzido durante os testes ao vivo do P-CACHE: `__('key')` retornava `"key"` até que `LANG_DRIVER=php` fosse definido.

```dotenv
LANG_DRIVER=php        # json | php — format of the language files
DEFAULT_LANG=fa        # boot language (Persian, RTL)
LANG_DIR=/Language
LANG_CACHE_TTL=60      # seconds the compiled map stays in cache
```

## O helper `__()` 

```php
// translations: 'welcome' => 'سلام #name خوش آمدی'
__('welcome', ['name' => 'علی']);          // "سلام علی خوش آمدی"
__('missing_key', 'پیش‌فرض');              // fallback when the key is absent
__('missing_key');                          // falls back to the key name itself
```

As substituições usam a sintaxe `#placeholder`; as chaves do mapa são escritas sem o `#`:

```php
__('greeting', 'default', ['name' => $firstName, 'count' => 3]);
```

Singleton de idioma:

```php
$lang = Language::getInstance();

$lang->setLanguage('en');        // switch language (per process — call it per update if users differ)
$lang->get('key', $default, $replacements);
$lang->has('key');               // exists in the current language?
$lang->getAll();                 // full flat map
$lang->getCurrentLanguage();

$lang->reloadLanguage('fa');     // drop cache + re-read files
$lang->clearCache();             // forget lang:* cache keys
$lang->getCacheStats();          // per-language entry counts + freshness
```

## Idioma por usuário em um plugin

O `Language` é um singleton por processo — o idioma atual se aplica a tudo que roda depois de `setLanguage()` naquele processo. Para seleção de idioma por usuário (implantações webhook/queue), resolva e defina-o no topo do handler:

```php
$userLang = $session->get('lang', 'fa');          // or read from your users table
Language::getInstance()->setLanguage($userLang);
$tg->sendMessage($chatId, __('menu_title'));
```

Em um daemon de polling de processo único, uma troca no meio de um update vaza para os updates seguintes a menos que você volte — prefira defini-lo por update incondicionalmente.

## Comportamento de cache (verificado)

O primeiro carregamento de um idioma lê os arquivos, achata o mapa e o armazena sob a chave de cache `lang:{lang}` com `LANG_CACHE_TTL`. Carregamentos subsequentes (incluindo processos novos) atingem o cache — a execução do P-CACHE mostrou o payload completo (`{"key":"value","btn.btna":"hi","main.ali":"asfaf132"}`) sobrevivendo cross-processo em `file`, `redis` e `memcached`, com o TTL do backend contando a partir de exatamente 60 s. Chaves de tradução ausentes são rastreadas em `lang:missing_keys` e descartadas uma vez por iteração de update (`Core::cleanup()` → `flushMissingKeys()`), o que torna a depuração de strings não traduzidas trivial — verifique o cache/logs pela lista de chaves.

## Scaffolding

```bash
php bin/tgbase make:language en     # creates Language/en.php scaffold
```

O `Language/fa.json.example` mostra o formato JSON caso você prefira arquivos JSON (e então defina `LANG_DRIVER=json`).
