# i18n — Language

فایل‌های ترجمه، هلپر `__()` و کش خودکار مپ‌های زبانِ کامپایل‌شده.

```php
use alirezax5\TelegramBase\App\Language\Language;
```

## چیدمان فایل‌ها

همه‌چیز زیر `LANG_DIR` قرار دارد (پیش‌فرض `/Language`، نسبت به ریشهٔ پروژه — `Bootstrap` مقدار `Paths::base() . LANG_DIR` را برایتان وصل می‌کند).

```
Language/
├── fa.php            # main file for 'fa' — keys as-is
└── fa/               # optional subdirectory — keys get a '<filename>.' prefix
    ├── main.php      #   → main.ali, main.other, …
    └── buttons.php   #   → buttons.save, buttons.cancel, …
```

- **فایل اصلی** `{LANG_DIR}/{lang}.php` است؛ **زیرشاخه** `{LANG_DIR}/{lang}/` است و همهٔ فایل‌های آن به ترتیب حروف الفبا با نام فایل به‌عنوان پیشوند کلید، بارگذاری می‌شوند.
- آرایه‌های تودرتو به **نماد نقطه‌ای** تخت می‌شوند: `['btn' => ['btna' => 'hi']]` → `btn.btna`.
- فرمت فایل از `LANG_DRIVER` پیروی می‌کند:

> ⚠️ **مقدار `LANG_DRIVER` باید با فرمت فایل‌های شما بخواند.** پیش‌فرض `json` است، اما مخزن فایل‌های آرایه‌ای PHP را همراه دارد (`fa.php`، `fa/main.php`) و `.env.example` مقدار `LANG_DRIVER="php"` را تنظیم می‌کند. در صورت ناهمخوانی (درایور json + فایل‌های .php) هر جستجویی بی‌صدا به نام کلید برمی‌گردد — نه خطایی، فقط متنی ترجمه‌نشده. دقیقاً همین سناریو در تست‌های زندهٔ P-CACHE بازتولید شد: `__('key')` مقدار `"key"` برمی‌گرداند تا وقتی `LANG_DRIVER=php` تنظیم شد.

```dotenv
LANG_DRIVER=php        # json | php — format of the language files
DEFAULT_LANG=fa        # boot language (Persian, RTL)
LANG_DIR=/Language
LANG_CACHE_TTL=60      # seconds the compiled map stays in cache
```

## هلپر `__()`

```php
// translations: 'welcome' => 'سلام #name خوش آمدی'
__('welcome', ['name' => 'علی']);          // "سلام علی خوش آمدی"
__('missing_key', 'پیش‌فرض');              // fallback when the key is absent
__('missing_key');                          // falls back to the key name itself
```

جایگذاری‌ها از سینتکس `#placeholder` استفاده می‌کنند؛ کلیدهای مپ بدون `#` نوشته می‌شوند:

```php
__('greeting', 'default', ['name' => $firstName, 'count' => 3]);
```

سینگلتون Language:

```php
$lang = Language::getInstance();

$lang->setLanguage('en');        // switch language (per process — call it per update if users differ)
$lang->get('key', $default, $replacements);
$lang->has('key');               // exists in the current language?
$lang->getAll();                 // full flat map
$lang->getCurrentLanguage();

$lang->reloadLanguage('fa');     // drop cache + re-read files
$lang->clearCache();             // forget lang:* cache keys
$lang->getCacheStats();          // per-language entry counts + freshness
```

## زبان هر کاربر داخل یک پلاگین

`Language` یک سینگلتون هر-پروسه است — زبان جاری بر همه‌چیزی که بعد از `setLanguage()` در آن پروسه اجرا شود اعمال می‌شود. برای انتخاب زبان هر کاربر (دیپلوی‌های وبهوک/صف)، آن را بالای هندلر resolve و تنظیم کنید:

```php
$userLang = $session->get('lang', 'fa');          // or read from your users table
Language::getInstance()->setLanguage($userLang);
$tg->sendMessage($chatId, __('menu_title'));
```

در یک دیمون polling تک-پروسه‌ای، تغییر زبان در میانهٔ یک آپدیت به آپدیت‌های بعدی سرایت می‌کند مگر اینکه برگردانید — بهتر است آن را به‌صورت بی‌قید و شرط برای هر آپدیت تنظیم کنید.

## رفتار کش (تأییدشده)

اولین بارگذاری هر زبان فایل‌ها را می‌خواند، مپ را تخت می‌کند و آن را زیر کلید کش `lang:{lang}` با `LANG_CACHE_TTL` ذخیره می‌کند. بارگذاری‌های بعدی (از جمله پروسه‌های تازه) به کش می‌خورند — اجرای P-CACHE نشان داد payload کامل (`{"key":"value","btn.btna":"hi","main.ali":"asfaf132"}`) به‌صورت بین‌پروسه‌ای روی `file`، `redis` و `memcached` باقی می‌ماند و TTL بک‌اند دقیقاً از 60 ثانیه شمارش معکوس می‌شود. کلیدهای ترجمهٔ گمشده در `lang:missing_keys` ردیابی می‌شوند و یک بار در هر تکرار آپدیت تخلیه می‌شوند (`Core::cleanup()` → `flushMissingKeys()`)، که دیباگ رشته‌های ترجمه‌نشده را ساده می‌کند — فهرست کلیدها را در کش/لاگ‌ها ببینید.

## اسکفولدینگ

```bash
php bin/tgbase make:language en     # creates Language/en.php scaffold
```

فایل `Language/fa.json.example` فرمت JSON را نشان می‌دهد اگر فایل‌های JSON را ترجیح می‌دهید (در آن صورت `LANG_DRIVER=json` را تنظیم کنید).

## لود تنبل `filename.key` (۲۰۲۶-۱۰)

میس روی کلید نقطه‌دار (مثلاً `__('shop.open')`) حالا یک‌بار
`Language/{lang}/shop.{php,json}` را لود و ادغام می‌کند — فایل‌هایی که بعد
از ساخت کش زبان اضافه شده‌اند (یا در بازهٔ TTL کهنه) شفاف حل می‌شوند، بدون
reload. پیشوند ناشناخته مستقیم به default برمی‌گردد؛ تلاش حداکثر یک‌بار در
هر درخواست برای هر پیشوند است.
