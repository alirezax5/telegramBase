# Конфигурация — полный справочник `.env`

Скопируйте [.env.example](../../.env.example) в `.env` и отредактируйте. Показанные значения — значения по умолчанию. Валидация при загрузке (`EnvironmentValidator`) проверяет критические из них и падает с читаемым сообщением вместо загадочного краха.

> Конфигурация только через реальные переменные окружения (systemd `Environment=`, `docker -e`, k8s) поддерживается в равной мере — `.env` необязателен. Когда существуют оба источника, окружение процесса побеждает (Dotenv неизменяем).

## Бот

| Ключ | По умолчанию | Примечания |
|------|--------------|------------|
| `BOT_TOKEN` | — | **обязателен**; от @BotFather. Валидируется по формату; никогда не выводится в сообщениях об ошибках. `TGBASE_SKIP_BOT_VALIDATION=1` позволяет DB-only CLI-командам работать без токена |
| `BOT_MODE` | `update_direct` | один из шести режимов — см. [bot-modes.md](bot-modes.md) |
| `BOT_API_URL` | `https://api.telegram.org` | переопределение для локальных Bot API серверов |
| `POLLING_TIMEOUT` | `30` | секунды long-poll на один вызов `getUpdates` |
| `POLLING_RESTART_INTERVAL` | `100` | батчей на один самоперезапуск (гигиена памяти; `0` отключает) |
| `BOT_WEBHOOK_URL` | — | URL конечной точки вебхука (HTTPS) |
| `BOT_WEBHOOK_SECRET` | — | секрет для `X-Telegram-Bot-Api-Secret-Token`; используйте 32+ случайных hex-символов (`openssl rand -hex 32`) |
| `WEBHOOK_CHECK_IP` | `true` | валидировать `REMOTE_ADDR` по подсетям Telegram — установите `false` за Cloudflare/прокси (тогда секрет — ваш слой аутентификации) |
| `DATA_DIR` | `AppData` | состояние времени выполнения (смещение, файлы очереди, блокировки) |

## Заметки по безопасности

- Никогда не коммитьте `.env`; прилагаемый `.gitignore` исключает его (также `*.secret` и `secrets.json`).
- Сообщения об ошибках `EnvironmentValidator` называют отсутствующий ключ, но никогда — его значение.
- Секреты вебхука сравниваются через `hash_equals()` (постоянное время).
- Специально **нет переключателя `VERIFY_TLS=false`** — проверка TLS для api.telegram.org всегда включена.
