# i18n — Language

Файлы переводов, хелпер `__()` и автоматическое кэширование скомпилированных языковых карт.

```php
use alirezax5\TelegramBase\App\Language\Language;
```

## Раскладка файлов

Всё лежит под `LANG_DIR` (по умолчанию `/Language`, разрешается относительно базовой папки проекта — `Bootstrap` сам подключает `Paths::base() . LANG_DIR`).

```
Language/
├── fa.php            # main file for 'fa' — keys as-is
└── fa/               # optional subdirectory — keys get a '<filename>.' prefix
    ├── main.php      #   → main.ali, main.other, …
    └── buttons.php   #   → buttons.save, buttons.cancel, …
```

- **Главный файл** — это `{LANG_DIR}/{lang}.php`; **подкаталог** — `{LANG_DIR}/{lang}/`, и каждый файл в нём загружается в алфавитном порядке с basename файла в качестве префикса ключа.
- Вложенные массивы сплющиваются в **точечную нотацию**: `['btn' => ['btna' => 'hi']]` → `btn.btna`.
- Формат файла определяется `LANG_DRIVER`:

> ⚠️ **`LANG_DRIVER` должен соответствовать формату ваших файлов.** По умолчанию — `json`, но в репозитории поставляются PHP-массивы (`fa.php`, `fa/main.php`), а `.env.example` задаёт `LANG_DRIVER="php"`. При несоответствии (json-драйвер + файлы .php) каждый поиск молча откатывается к имени ключа — без ошибки, просто непереведённый текст. Этот точный сценарий был воспроизведён во время живых тестов P-CACHE: `__('key')` возвращало `"key"`, пока не был установлен `LANG_DRIVER=php`.

```dotenv
LANG_DRIVER=php        # json | php — format of the language files
DEFAULT_LANG=fa        # boot language (Persian, RTL)
LANG_DIR=/Language
LANG_CACHE_TTL=60      # seconds the compiled map stays in cache
```

## Хелпер `__()`

```php
// translations: 'welcome' => 'سلام #name خوش آمدی'
__('welcome', ['name' => 'علی']);          // "سلام علی خوش آمدی"
__('missing_key', 'پیش‌فرض');              // fallback when the key is absent
__('missing_key');                          // falls back to the key name itself
```

Подстановки используют синтаксис `#placeholder`; ключи карты записываются без `#`:

```php
__('greeting', 'default', ['name' => $firstName, 'count' => 3]);
```

Синглтон Language:

```php
$lang = Language::getInstance();

$lang->setLanguage('en');        // switch language (per process — call it per update if users differ)
$lang->get('key', $default, $replacements);
$lang->has('key');               // exists in the current language?
$lang->getAll();                 // full flat map
$lang->getCurrentLanguage();

$lang->reloadLanguage('fa');     // drop cache + re-read files
$lang->clearCache();             // forget lang:* cache keys
$lang->getCacheStats();          // per-language entry counts + freshness
```

## Язык по пользователю в плагине

`Language` — синглтон на процесс; текущий язык применяется ко всему, что выполняется после `setLanguage()` в этом процессе. Для выбора языка по пользователю (webhook/queue-развёртывания) определяйте и устанавливайте его в начале хендлера:

```php
$userLang = $session->get('lang', 'fa');          // or read from your users table
Language::getInstance()->setLanguage($userLang);
$tg->sendMessage($chatId, __('menu_title'));
```

В однопроцессном polling-демоне переключение посреди обновления протечёт в последующие обновления, если не переключиться обратно — предпочтительнее устанавливать его для каждого обновления безусловно.

## Поведение кэширования (проверено)

Первая загрузка языка читает файлы, сплющивает карту и сохраняет её под ключом кэша `lang:{lang}` с `LANG_CACHE_TTL`. Последующие загрузки (включая свежие процессы) попадают в кэш — прогон P-CACHE показал полную полезную нагрузку (`{"key":"value","btn.btna":"hi","main.ali":"asfaf132"}`), переживающую смену процесса на `file`, `redis` и `memcached`, с TTL бэкенда, отсчитывающимся ровно от 60 с. Отсутствующие ключи переводов отслеживаются в `lang:missing_keys` и сбрасываются один раз за итерацию обновления (`Core::cleanup()` → `flushMissingKeys()`), что делает отладку непереведённых строк тривиальной — проверьте список ключей в кэше/логах.

## Скаффолдинг

```bash
php bin/tgbase make:language en     # creates Language/en.php scaffold
```

`Language/fa.json.example` показывает формат JSON, если вы предпочитаете JSON-файлы (тогда установите `LANG_DRIVER=json`).
